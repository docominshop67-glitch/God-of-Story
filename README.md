# 🇹🇭 Docomin - ศูนย์กลางการเรียนรู้และการสอบครบวงจร ป.1 - ม.6 (Full-Stack Platform)

เว็บไซต์รวบรวมองค์ความรู้ตามหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน (สพฐ.) ครอบคลุม **12 ระดับชั้น (ป.1 - ม.6)** และ 9 กลุ่มสาระการเรียนรู้ พร้อม **โหมดเปิดอ่านหนังสือเสมือนจริง (E-Book Reader)**, **คลังข้อสอบระดับชาติ (O-NET, NT, สอบเข้า ม.1/ม.4, TCAS A-Level, TGAT)**, **ศูนย์ข้อมูลข่าวสารรับสมัครสอบ & แจ้งเตือนโรงเรียนดัง**, **สารานุกรมค้นคว้าความรู้ (Wiki)**, **77 จังหวัดไทย**, และ **มินิเกมฝึกสมอง**

---

## 🌟 ฟังก์ชั่นหลักและระบบที่ครอบคลุม:

### 1. 📢 ศูนย์ข้อมูลข่าวสารการสอบ & ปฏิทินรับสมัคร ม.1 / ม.4 / TCAS:
- URL: `/admissions/`
- รวบรวมกำหนดการรับสมัครและปฏิทินสอบคัดเลือกของโรงเรียนชั้นนำระดับประเทศ:
  - 🏫 ม.4: เตรียมอุดมศึกษา, กำเนิดวิทย์ (KVIS), มหิดลวิทยานุสรณ์ (MWIT), จุฬาภรณราชวิทยาลัย 12 แห่ง, สาธิต มศว ประสานมิตร, บดินทรเดชา, ขอนแก่นวิทยายน
  - 🎒 ม.1: สวนกุหลาบวิทยาลัย (GATE), สตรีวิทยา (Gifted)
  - 🎓 ม.6 TCAS68: กสพท (แพทย์/ทันตะ/เภสัช/สัตวแพทย์), TGAT/TPAT, A-Level
  - 🏆 โอลิมปิกวิชาการ สอวน. ทุกสาขาวิชา
- **🔔 ระบบแจ้งเตือนโรงเรียนโปรด (School Alert Toggle):** นักเรียนสามารถกดกระดิ่งแจ้งเตือนโรงเรียนที่สนใจเพื่อติดตามสถานะได้ทันที
- ตัวกรองอัจฉริยะ: ค้นหาตามระดับชั้น, ภูมิภาค, และสถานะการรับสมัคร พร้อมเวลานับถอยหลัง (Countdown)

### 2. 🎖️ คลังข้อสอบระดับชาติ & เทคนิคคิดลัด (Massive Exam Bank with Shortcuts):
- URL: `/quiz/`
- รวบรวมข้อสอบจัดเต็มพร้อม **เทคนิคคิดลัดและคำอธิบายละเอียดครบทุกข้อ**:
  - 🎖️ **O-NET:** ป.6, ม.3, ม.6 มาตรฐาน สทศ.
  - 📝 **NT (National Test):** ป.3 วัดทักษะคณิตศาสตร์และภาษาไทย
  - 🏫 **สอบเข้า ม.1 & ม.4:** สำหรับสอบเข้าโรงเรียนแข่งขันสูง
  - 🎓 **TCAS A-Level & TGAT 2:** คณิตศาสตร์ประยุกต์, ฟิสิกส์, และการคิดอย่างมีเหตุผล
- ระบบจับเวลาจริง, หลอดความคืบหน้า (Progress bar), การตรวจคำตอบอัตโนมัติ, และพลุเฉลิมฉลอง (Confetti)

### 3. 📖 โหมดเปิดอ่านหนังสือเสมือนจริง (E-Book Textbook Reader):
- URL: `/book/<id>`
- พลิกหน้าหนังสือซ้าย-ขวา พร้อมเอฟเฟกต์เสียงพลิกหน้ากระดาษ (Flip Sound)
- สารบัญบทเรียนดึงออกได้ (Table of Contents Drawer)
- รองรับปุ่มลัดคีย์บอร์ด (ลูกศรซ้าย/ขวา), การปรับขนาดฟอนต์, และระบบอ่านออกเสียงภาษาไทย (TTS)

### 4. 🌙 โหมดกลางคืนสมบูรณ์แบบ (100% Comprehensive Dark Mode):
- สลับโทนสีถนอมสายตาด้วยดีไซน์ Deep Slate & Navy ทันสมัย
- รองรับทั้งการบันทึกสถานะผ่าน LocalStorage และ Attribute `data-bs-theme="dark"`

### 5. 🔍 สารานุกรมความรู้ประเทศไทย & 77 จังหวัด (Wiki & Thailand Atlas):
- URL: `/wiki/` และ `/thailand/`
- รวบรวมสูตรคณิตศาสตร์, ตารางธาตุ, วรรณคดีไทย, ประวัติศาสตร์ราชวงศ์จักรี, และข้อมูลเชิงลึก 77 จังหวัดทั่วไทย

### 6. 🎮 ศูนย์รวมมินิเกมฝึกสมอง (Educational Games Hub):
- URL: `/games/`
- คิดเลขเร็วสายฟ้าแลบ (Speed Math), จับคู่คำศัพท์ภาษาอังกฤษ (Word Match), และเกมทายภูมิศาสตร์ไทย (Geo Quiz)

## 🚀 วิธีการรันระบบภายในเครื่อง (Local Run)

เปิด Terminal หรือ Command Prompt ในโฟลเดอร์โปรเจกต์:
```bash
py app.py
```
เข้าใช้งานผ่านเบราว์เซอร์:
👉 **http://localhost:5000**

## 💻 การอัปโหลดขึ้น GitHub (Git & GitHub)

ระบบผูก Remote Origin ไว้กับ GitHub Repository แล้ว:
```bash
# 1. ตรวจสอบสถานะ
git status

# 2. ทำการ Push ขึ้น GitHub
git push -u origin master
```
*(หากยังไม่ได้เข้าสู่ระบบ GitHub หรือต้องการใส่ Personal Access Token สามารถใช้คำสั่ง: `git push https://<TOKEN>@github.com/antiny817-crypto/docomin.git master`)*
